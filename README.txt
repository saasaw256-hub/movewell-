MoveWell — Weekly Tracker

CONTENTS
- index.html: the tracker
- manifest.webmanifest: installable app settings
- sw.js: offline cache
- icon.svg: app icon

USE
1. Open index.html in a browser for a basic local preview.
2. For installation and offline support, host the entire folder on an HTTPS static host.
3. Open the hosted HTTPS address in Chrome or Edge and choose Install (or use the browser's install option).

Progress and notes are stored in the browser on the device where you use the tracker.
They are not synced between devices. Clearing browser site data may erase them.

The workout is a general, gentle routine. Use comfortable effort, take recovery days,
and stop if you experience pain. The schedule is three non-consecutive workout days.
